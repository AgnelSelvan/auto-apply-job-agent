# Apply For Job

A tool to search and scrape jobs using a local SearXNG instance.

## Installation

```bash
pip install -e .
```

## Usage

```bash
apply-for-job "software engineer python" -l "Bangalore, Remote"
```

If you don't provide a query or location, the tool will prompt you for them interactively:

Or run interactively:
```bash
apply-for-job
```

## Development

```bash
pip install -e ".[dev]"
pytest
```
